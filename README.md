# GreenFarm（绿野农场）

轻度经营 + 好友互动的微信小游戏农场项目。

## 项目结构

```text
GreenFarm/
├── Docs/        产品与技术文档（唯一真相来源，Claude Code 按此开发）
├── Assets/      美术资源（UI / Crops / Buildings / Icons / Characters / Audio / Fonts）
├── Client/      小游戏客户端代码
├── Server/      服务端代码
└── README.md
```
