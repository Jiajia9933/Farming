# 建筑系统

## 仓库（已实现）

- 存放收获的作物，20 级前用金币升级，等级/容量/花费规则见 [13_游戏规则.md](13_游戏规则.md)，具体数值在 `Client/config/warehouse.json`。
- 目前没有单独的"商店"，仓库场景里放了一个"全部卖出"按钮做临时代替（一次性把库存全部按 `Client/config/plants.json` 的 `sellPrice` 换成金币）。真正的商店（分作物卖、可能有折扣/税率等）留到商店设计定了再做。
