# 任务系统（每日订单等）

## 每日订单（已实现）

- 从固定订单池（`Client/config/orders.json`）里按当天日期挑一个，同一天固定不变，不是随机。
- 交订单需要仓库里有对应数量的作物，交了之后扣库存换金币+经验，一天只能交一次。
- 奖励规则：需求作物的 sellPrice/exp 总和 × 1.5，比直接卖仓库划算，鼓励做订单而不是无脑"全部卖出"。
- 入口在仓库场景（[06_建筑系统.md](06_建筑系统.md)）里，紧跟在库存列表下面。
