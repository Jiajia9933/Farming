# CHANGELOG

## 2026-08-04 — Version 0.7.1

新增：

- 地块之间不再留背景色缝隙，10 块地贴在一起
- 新增场景装饰（`Client/src/ui/Scenery.ts`）：草地背景、天空带+云朵、地块四周的木栅栏
- 好友农场占位场景同步用了同样的背景/栅栏，风格一致

## 2026-08-04 — Version 0.7.0

新增：

- 地块背景改成带纹理的土壤贴图（犁沟线+土块斑点，`Client/src/ui/LandTile.ts`），不再是纯色方块
- 作物三阶段生长视觉：发芽🌱（进度<50%）→ 半成熟🌿（50%~100%，还看不出具体作物）→ 成熟后显示作物自己的图标+金色边框高亮
- 好友农场占位场景同步使用新土壤贴图和生长图标，视觉风格保持一致

## 2026-08-04 — Version 0.6.2

调整（UI，反馈调整上一版）：

- 按钮/标题/状态提示改回中文文字（拜访好友、仓库、地图、返回、取消、签到、金币、经验等），只有作物保留 emoji 图标
- 地块背景色不再随成熟状态变色（之前橙色背景跟胡萝卜的橙色图标撞在一起不好看），统一用土色背景，成熟改用金色边框高亮表示

## 2026-08-04 — Version 0.6.1

调整（UI）：

- 全部按钮/状态文字尽量换成图标（emoji），减少界面文字：金币💰、经验⭐、拜访好友👥、仓库📦、地图🗺️、返回🔙、取消✖️、签到🎁、可收获✅等
- 作物新增 `icon` 字段（`Client/config/plants.json`），地块、种植菜单、仓库库存列表都用图标代替作物名文字
- 真实数据类文字（好友名字等）保留，图标只替换纯粹的按钮/标签文字

## 2026-08-04 — Version 0.6.0

新增：

- 每日订单：仓库场景新增"今日订单"区块，从固定订单池（`Client/config/orders.json`）按日期挑一个，同一天不变；交订单扣仓库库存，换金币+经验，一天限交一次
- 订单奖励按需求作物 sellPrice/exp 总和 × 1.5 计算，比直接"全部卖出"划算

## 2026-08-04 — Version 0.5.2

修复：

- 存档读取改成跟默认值浅合并，不再假设旧存档已经有全部字段。旧存档缺 `inventory`/`warehouseLevel` 导致 `this.inventory` 是 `undefined`，一进仓库场景或点收获就在 `Object.values(undefined)` 上崩溃（仓库白屏、收获没反应）

## 2026-08-04 — Version 0.5.1

新增：

- 每次收获额外给固定5金币（不管什么作物），见 `Client/config/harvest.json`；作物本身的钱仍然要卖仓库库存才有
- 金币来源明确为：签到 + 收获固定金币 + 卖仓库作物 + 以后的订单系统（[08_任务系统.md](08_任务系统.md)，还没做）

## 2026-08-04 — Version 0.5.0

新增：

- 仓库系统：1~20级，每级容量+10（20级=200），花费=当前等级×100金币（`Client/config/warehouse.json`）
- 首页新增"仓库"入口按钮，新场景可以看库存、升级仓库、一键"全部卖出"、返回首页

调整（行为变更）：

- 收获不再直接换金币：作物先进仓库占容量，经验依然立刻到手；仓库满了收获会失败，作物留在地里不会丢
- 卖钱统一改成在仓库里点"全部卖出"（真正的商店——分作物卖、可能有折扣等——还没做，见 [06_建筑系统.md](06_建筑系统.md)）

## 2026-08-04 — Version 0.1.1

修复：

- 作物配置改为通过 `wx.getFileSystemManager().readFileSync` 读取 `config/plants.json`，因为微信小游戏的 `require` 不支持直接加载 `.json` 文件
- HUD 顶部资源栏改用 `wx.getMenuButtonBoundingClientRect()` 计算安全区域，避免被刘海屏/状态栏遮挡
