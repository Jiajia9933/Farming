# CHANGELOG

## 2026-08-04 — Version 0.6.0

新增：

- 每日订单：仓库场景新增"今日订单"区块，从固定订单池（`Client/config/orders.json`）按日期挑一个，同一天不变；交订单扣仓库库存，换金币+经验，一天限交一次
- 订单奖励按需求作物 sellPrice/exp 总和 × 1.5 计算，比直接"全部卖出"划算

## 2026-08-04 — Version 0.5.2

修复：

- 存档读取改成跟默认值浅合并，不再假设旧存档已经有全部字段。旧存档缺 `inventory`/`warehouseLevel` 导致 `this.inventory` 是 `undefined`，一进仓库场景或点收获就在 `Object.values(undefined)` 上崩溃（仓库白屏、收获没反应）

## 2026-08-04 — Version 0.5.1

新增：

- 每次收获额外给固定5金币（不管什么作物），见 `Client/config/harvest.json`；作物本身的钱仍然要卖仓库库存才有
- 金币来源明确为：签到 + 收获固定金币 + 卖仓库作物 + 以后的订单系统（[08_任务系统.md](08_任务系统.md)，还没做）

## 2026-08-04 — Version 0.5.0

新增：

- 仓库系统：1~20级，每级容量+10（20级=200），花费=当前等级×100金币（`Client/config/warehouse.json`）
- 首页新增"仓库"入口按钮，新场景可以看库存、升级仓库、一键"全部卖出"、返回首页

调整（行为变更）：

- 收获不再直接换金币：作物先进仓库占容量，经验依然立刻到手；仓库满了收获会失败，作物留在地里不会丢
- 卖钱统一改成在仓库里点"全部卖出"（真正的商店——分作物卖、可能有折扣等——还没做，见 [06_建筑系统.md](06_建筑系统.md)）

## 2026-08-04 — Version 0.4.1

新增：

- 补齐五种作物：新增土豆（180/260，8分钟，80经验）、西瓜（300/450，15分钟，150经验），凑齐 [12_开发计划.md](12_开发计划.md) 第二周要求的五种植物
- 纯配置改动，种植菜单/地块渲染代码不用改，自动读取全部作物

## 2026-08-04 — Version 0.4.0

新增：

- 每日签到：每天首次进入首页弹窗领取金币（默认10金币，见 `Client/config/checkin.json`），未签到状态和日期存进本地存档
- 抽出通用配置读取工具 `ConfigLoader.ts`，`PlantConfig.ts` 和新的 `CheckInConfig.ts` 共用

## 2026-08-04 — Version 0.3.0

新增：

- 场景切换架构（`Scene` 接口 + `game.ts` 里的场景管理），首页新增"拜访好友"按钮
- 地图场景：两个入口卡片——我的农场 / 好友农场
- 好友农场占位场景：假数据展示，能返回地图，暂不可交互（点赞/浇水/送礼等真实好友互动等服务器和好友数据就绪后再做，见 [07_好友系统.md](07_好友系统.md)）

## 2026-08-04 — Version 0.2.1

新增：

- 种植菜单每种作物显示成熟时间

调整：

- 作物成熟时间改为胡萝卜1分钟/玉米2分钟/番茄5分钟（方便测试）
- 经验值改为按成熟时间正比计算：每1分钟成熟时间=10经验（胡萝卜10/玉米20/番茄50）

## 2026-08-04 — Version 0.2.0

新增：

- 种植菜单支持多种作物选择（胡萝卜/玉米/番茄，数值见 `Client/config/plants.json`，对应 [04_经济系统.md](04_经济系统.md)），金币不够的作物在菜单里禁用
- 地块生长/成熟状态显示具体作物名称

修复：

- HUD 安全区域改用 `wx.getSystemInfoSync().statusBarHeight`，替换掉不稳定的 `getMenuButtonBoundingClientRect`

## 2026-08-04 — Version 0.1.1

修复：

- 作物配置改为通过 `wx.getFileSystemManager().readFileSync` 读取 `config/plants.json`，因为微信小游戏的 `require` 不支持直接加载 `.json` 文件
- HUD 顶部资源栏改用 `wx.getMenuButtonBoundingClientRect()` 计算安全区域，避免被刘海屏/状态栏遮挡

## 2026-08-03 — Version 0.1.0

新增：

- 微信小游戏客户端工程搭建（TypeScript + 原生框架，`Client/project.config.json` / `game.json`）

- 点击空地弹出种植菜单，可种植胡萝卜（购买价 20，售价 30，成熟 5 分钟，经验 5，见 `Client/config/plants.json`）
