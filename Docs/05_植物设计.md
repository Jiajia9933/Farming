# 植物设计

已实现 5 种作物：胡萝卜、玉米、番茄、土豆、西瓜。具体数值（买入/卖出/成熟时间/经验）不在这里重复维护，见 [04_经济系统.md](04_经济系统.md) 和 `Client/config/plants.json`，避免两处数字不一致。

## 生长的视觉状态（已实现）

美术资源还没做（[10_美术规范.md](10_美术规范.md)），现在用 emoji 表示三个生长阶段：

```
发芽（进度 <50%）   sproutIcon   小图标，每种作物不一样
半成熟（50%~100%）  growingIcon  中图标，每种作物不一样
成熟（100%）        icon         作物自己的图标，大图标，配金色边框高亮
```

发芽/半成熟阶段每种作物用不同的 emoji（见 `Client/config/plants.json` 里的 `sproutIcon`/`growingIcon` 字段），不是所有作物共用一个通用图标，方便没成熟的时候也能大致分辨种的是什么。点一下生长中（未成熟）的地块，底部文字会从倒计时换成作物名字，再点一下换回倒计时。

地块本身用带纹理的土壤背景（犁沟线 + 土块斑点，见 `Client/src/ui/LandTile.ts`），不是纯色方块。收获后地块变回空地。

## 新增植物的步骤

1. 在 `Client/config/plants.json` 加一条配置（含 `icon`/`sproutIcon`/`growingIcon` 三个 emoji 字段，三个尽量跟其他作物不重复；`requiredLevel` 决定玩家几级能种）。
2. 在 [04_经济系统.md](04_经济系统.md) 的表格里加一行同步数值（含解锁等级）。
3. 不用改代码——种植菜单、地块渲染、仓库库存都会自动读取新配置。
