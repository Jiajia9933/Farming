# 游戏规则（Game Rules）

所有规则写死在这里，AI 开发时不自行猜测。任何规则变更需先改这份文档，再改代码。

```text
成熟：服务器时间计算
离线：继续成长
金币：不能出现负数
土地：默认 10 块
仓库：有等级上限的有限容量，20级前可用金币升级；容量/升级花费见 Client/config/warehouse.json（当前 20级=200 容量，每级容量+10，升级花费=当前等级×100金币）
收获：作物先进仓库，不直接换钱；每次收获额外给固定金币（不管什么作物，当前5金币，见 Client/config/harvest.json）；经验在收获时立刻到手；仓库满了收获会失败，作物留在地里
金币来源：签到奖励 + 每次收获的固定金币 + 卖仓库作物 + 以后的订单系统（见 [08_任务系统.md](08_任务系统.md)）
每日签到：每天进游戏第一次可领取，奖励金币见 Client/config/checkin.json（当前 10 金币）
```

当前实现的限制：还没有服务器，"每日签到"和"成熟时间"暂时都用设备本地时间判断，玩家改设备时间可以刷奖励/加速成熟。等 [11_技术架构.md](11_技术架构.md) 的服务端方案定下来后需要改成服务器时间校验。
