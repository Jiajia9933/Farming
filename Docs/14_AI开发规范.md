# AI 开发规范（AI Development Guide）

Claude Code 在这个项目里只遵守这份文档的规范。

```text
所有代码：TypeScript
禁止重复代码
所有配置：JSON
UI：组件化
每个模块：单独文件
```

## 补充说明

- 数值类配置（作物、经济、规则）一律来自 `Docs/` 对应文档，不允许在代码中硬编码魔法数字。
- 新增功能前，先确认对应的 Docs 文档是否已有明确规则；没有的话，先补文档，再写代码（占位文档标注"待设计"的模块除外，此类模块暂不实现）。
- 每完成一个可交付的功能点，更新一次 [CHANGELOG.md](CHANGELOG.md)。
- 提交前跑通微信开发者工具的基本预览，再进入下一个任务。
